> 서용태 님(@rundevelrun)의 개인 자산 스케일업을 위한 완전 자동화 알고리즘 트레이딩 시스템

## 📌 1. 시스템 아키텍처 (클라우드 비서 & 홈 서버 분업)

본 시스템은 **클라우드 AI(피클 비서)**와 **집 리눅스 노트북(실행 엔진)**이 GitHub를 매개로 유기적으로 협업하는 24/7 무중단 트레이딩 아키텍처입니다.

```text
[집 리눅스 노트북 (홈 서버)]
   │  - 24/7 systemd 무중단 데몬 가동
   │  - 장중 1분 주기 키움 REST API 시세 감시 및 조건 평가
   │  - 조건 부합 시 즉시 자동 주문 (매수/매도 집행)
   │
   ├─► [체결 발생 시] ──► GitHub main 브랜치 (trades.json 업데이트)
   │                             │
   │                             ▼
   │                   [피클 비서 (클라우드)]
   │                      - 30분 주기 체커(check.sh)로 감지 (토큰 0원)
   │                      - 체결 즉시 용태 님 스마트폰으로 실시간 알림!
   │                      - 매주 월요일 08:00 주간 결산 & 전략 진단 선보고
   │
   └─► [30분 주기 생존 핑] ──► GitHub status 브랜치 (단일 커밋 덮어쓰기)
                                 │ (0.1KB, 메인 잔디/히스토리 오염 0%)
                                 ▼
                       [스마트폰에서 "봇 잘 돌아?" 질문 시 즉시 1초 브리핑!]
```

## 🛡️ 2. 핵심 전략: 비대칭 손익비 저격매매 (Asymmetric Risk-Reward)

### ① 감시 유니버스: 시총 1조 ~ 5조 원 황금 탄력 구간 (Dynamic Screener)
- **잡주·작전주 원천 배제**: 시가총액 1조 원 미만 종목, 우선주, 스팩(SPAC), ETN을 원천 차단하여 기관·외인 패시브 자금이 들어오는 최소 안전선을 확보합니다.
- **굼뜬 메가캡 배제**: 시가총액 5조 원을 초과하는 10조~1,000조 대형 코끼리(삼전 등)를 제외하여, 지수에 끌려다니지 않고 주도 섹터 수급 유입 시 시원하게 슈팅하는 종목만 발굴합니다.
- **실시간 거래대금 정렬**: 매일 아침 장 시작 전 당일 거래대금 최상위 20종목을 실시간 추출하여 매일 유니버스를 자동 갱신합니다.

### ② 2대 콤비 진입 전략
1. **과매도 줍줍 저격매수 (RSI Reversal)**:
   - 14일 RSI가 **28.0 이하**로 급락한 우량주를 공포 구간에서 역발상 분할 매수.
2. **추세 필터 변동성 돌파 (Trend VBO)**:
   - 주가가 20일 이동평균선 위에 위치한 확실한 우상향 추세에서만 전일 변동폭(K=0.5) 돌파 시 모멘텀 매수.

### ③ 4대 철벽 안전장치 (자금 및 리스크 관리)
1. **-2.0% 기계적 칼손절**: 어떤 이유든 진입가 대비 -2% 도달 시 즉시 시장가 전량 청산 (치킨값 수준 손실 방어).
2. **트레일링 스탑 (수익 잠금)**: 주가가 **+4.0%** 도달 시 손절선을 본전 위(**+1.0%**)로 자동 상향하여 확정 수익을 방어.
3. **+8.0% 목표 익절**: 진입가 대비 +8% 도달 시 시원하게 전량 차익 실현.
4. **타임스탑 & 일일 킬스위치**: 최대 7거래일 내 미청산 시 정리하며, 하루 누적 손실 -4% 도달 시 당일 모든 신규 매매를 셧다운.
5. **자금 배분**: 계좌 총자산의 종목당 최대 20%, 최대 4종목 동시 보유 (최소 20% 현금 버퍼 상시 유지).

## 🚀 4. 집 리눅스 노트북 설치 및 가동 방법

### 1단계: 저장소 클론 및 가상환경 세팅
```bash
# 1. 저장소 클론
git clone https://github.com/rundevelrun/quant-sniper.git
cd quant-sniper

# 2. 파이썬 가상환경 생성 및 활성화
python3 -m venv venv
source venv/bin/activate

# 3. 필수 라이브러리 설치
pip install requests
```

### 2단계: 키움 API 모의투자 키 입력 (.env)
```bash
cp .env.example .env
nano .env
```
`.env` 파일에 발급받으신 키움증권 REST API 모의투자 키를 입력하고 저장합니다 (`Ctrl+O` ➔ `Enter` ➔ `Ctrl+X`):
```env
KIWOOM_APP_KEY=발급받은_모의투자_APP_KEY
KIWOOM_APP_SECRET=발급받은_모의투자_APP_SECRET
KIWOOM_ACCOUNT_NO=모의투자_계좌번호_8자리
KIWOOM_ACCOUNT_TYPE=01
KIWOOM_USE_MOCK=true
```
*(※ `.env` 파일은 `.gitignore`에 등록되어 있어 GitHub에 절대 올라가지 않습니다.)*

### 3단계: Git 푸시 권한 1회 확인
봇이 체결 내역과 상태를 GitHub에 안전하게 푸시할 수 있도록 노트북에 GitHub 인증을 확인합니다.
```bash
# GitHub CLI 로그인 (가장 간편한 방법)
gh auth login
# 브라우저 또는 일회성 코드로 인증 완료
```

### 4단계: 봇 가동 (2가지 방법 중 선택)

#### 방법 A: 스크립트 백그라운드 실행
```bash
chmod +x run.sh
./run.sh
```
- 실행 즉시 Git 푸시 권한을 1초 만에 사전 검증합니다.
- `nohup`으로 구동되어 터미널을 닫거나 SSH 세션이 끊겨도 백그라운드에서 죽지 않고 계속 돕니다.

#### 방법 B: systemd 데몬 등록 (가장 강력 추천! 🌟)
```bash
sudo cp quant_sniper.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now quant_sniper
```
- **자동 부활 (`Restart=always`)**: 코드 예외로 죽어도 10초 만에 자동 재시작됩니다.
- **부팅 시 자동 시작**: 노트북이 꺼졌다가 켜져도 부팅 즉시 봇이 알아서 돌아갑니다.

## 💻 5. 노트북 덮개 닫힘 시 절전 방지 설정 (필수!)

노트북을 덮어두고 홈 서버로 쓸 경우, 절전 모드로 진입하지 않도록 리눅스 설정을 적용합니다:
```bash
sudo nano /etc/systemd/logind.conf
```
아래 항목을 찾아 주석(`#`)을 풀고 `ignore`로 변경합니다:
```ini
HandleLidSwitch=ignore
HandleLidSwitchExternalPower=ignore
HandleLidSwitchDocked=ignore
```
저장 후 데몬을 재시작합니다:
```bash
sudo systemctl restart systemd-logind
```

## 🤖 7. 피클 비서 연동 및 보고 스케줄

1. **장중 실시간 체결 알림 (`every 30m`)**:
   - 집 노트북에서 매수/매도 주문이 체결되면 `trades.json`에 기록되고 `main` 브랜치로 푸시됩니다.
   - 피클 비서의 장중 감시 스케줄(`check.sh`)이 이를 감지하여 용태 님께 즉시 체결 알림(종목명, 단가, 수량, 실현손익)을 쏩니다. (거래가 없을 시 토큰 소모 0원)
2. **주간 성과 결산 및 전략 진단 (`weekly mon 08:00`)**:
   - 매주 월요일 오전 8시(장 개장 1시간 전), 비서가 지난 한 주간의 누적 거래 내역(승률, 실현손익, MDD, 슬리피지)을 전수 분석합니다.
   - 주간 영수증 카드와 함께 **"현재 파라미터 유지"** 또는 **"시장 변동성에 맞춘 파라미터 수정 권고 리포트"**를 선보고합니다.

## 📂 8. 프로젝트 폴더 구조

```text
quant-sniper/
├── config.py             # 1조~5조 시총 필터, 손익비 파라미터, 키움 API 설정
├── screener.py           # 당일 거래대금 TOP 우량주 실시간 동적 스크리너 (1조~5조)
├── strategy.py           # RSI 과매도 반등 및 변동성 돌파 시그널 평가 엔진
├── kiwoom_api.py         # 키움증권 REST API 래퍼 (시세 조회, 매수/매도 주문)
├── bot.py                # 24/7 메인 감시 루프 및 status 브랜치 헬스체크 엔진
├── run.sh                # Git 권한 사전 검증 및 nohup 백그라운드 실행기
├── quant_sniper.service  # systemd 무중단 자동 재시작 서비스 파일
├── trades.json           # 누적 체결 장부 (비서 실시간 동기화용)
├── positions.json        # 현재 보유 포지션 관리 장부
├── health.json           # 로컬 1분 주기 헬스체크 파일 (150바이트 단일 객체)
├── .env.example          # 키움 API 키 템플릿
└── .gitignore            # 민감 파일(.env 등) 깃 제외 목록
```
