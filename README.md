# 🎯 quant-sniper
> **키움증권 REST API 기반 자동매매 시스템**
> 기본값은 모의투자이며, 실전 모드는 명시적인 이중 안전 설정을 해야만 활성화됩니다.

---

## ⚠️ 1. 리스크 고지 및 전략 한계 (솔직한 검증 진단)

본 시스템은 **"확정 고수익"을 보장하는 완성형 투자 상품이 아닙니다.**  
외부 전문 퀀트 코드 리뷰 및 엄밀한 금융공학적 검증 결과, 다음 한계와 위험 요소를 명확히 인지하고 운용해야 합니다:

1. **1년 백테스트의 표본 한계**:  
   250거래일(1년) 데이터는 다양한 시장 국면(상승·하락·횡보·급락장)을 모두 검증하기에 짧으며, 특정 상승장 장세에 과최적화(Overfitting)되었을 가능성이 있습니다.
2. **거래비용과 슬리피지 영향**:  
   국내 증권거래세(0.18%)와 위탁수수료, 시장가 주문 시 발생하는 슬리피지(왕복 약 0.41% 이상)는 잦은 단기 회전 매매 전략의 누적 수익률을 유의미하게 갉아먹을 수 있습니다.
3. **시장 급변동 및 갭 하락 리스크**:  
   개장 직후 대형 악재로 인한 갭 하락 시 기계적 손절선이나 일일 킬스위치가 의도한 지정 가격에서 체결되지 않고 추가 손실을 초래할 수 있습니다.
4. **운용 원칙**:  
   따라서 본 봇은 **"수익 보장 봇"이 아니라 "검증할 가치가 있는 통계적 가설을 안전하게 테스트하는 도구"**입니다. 처음부터 큰 시드를 투입하지 않고, **10만~30만 원 수준의 극소액으로 체결 안정성과 실전 손익비를 철저히 검증한 뒤 점진적으로 스케일업**하는 것을 절대 원칙으로 합니다.

## 💡 2. 7대 퀀트 정석 피드백 반영 및 고도화 내역

엄밀한 외부 퀀트 피드백을 수용하여 코드 베이스 전반을 아래와 같이 대폭 고도화했습니다:

| 구분 | 기존 한계 | 고도화 반영 내역 (현재 코드) |
|---|---|---|
| **손절 로직** | 고정 -2.0% 칼손절 (과매도 변동성에 휩소 노이즈 빈발) | **ATR(14) 변동성 기반 동적 손절** 도입 (2.5%~4.0% 밴드 연동) |
| **손익비 구조** | 고정 -2% / +8% (변동성 불일치) | **최소 손익비 1:2 원칙 보장** (목표 익절폭 = 손절폭 × 2.0 이상) |
| **거래비용 반영** | 거래비용 미반영 단순 계산 | **거래세(0.18%) + 수수료 + 슬리피지(왕복 0.41%) 실질 차감** PnL 계산 |
| **미래정보 차단** | 장전 스크리너 데이터 기준 모호성 (Lookahead 의혹) | **전일(D-1) 장마감 확정 정산 데이터만 조회**하도록 명문화 및 고정 |
| **유니버스 정렬** | 시총 1조~5조 탄력 구간 유지 | 우선주·스팩·ETN 원천 차단 및 전일 실질 거래대금 최상위 20종목 동적 추출 |
| **성과 표현** | +80%~+182% 과대포장 수치 노출 | **단순 약식 가설치로 격하**하고, 실전 소액 포워드 테스트 결과 중심으로 전환 |
| **자금 관리** | 종목당 20%, 최대 4종목 (현금 20% 버퍼) | **10만 원 소액 테스트(1주 단위 매수)** 완벽 지원 및 일일 -4% 킬스위치 유지 |

## 📌 3. 시스템 아키텍처 (클라우드 비서 & 홈 서버 분업)

본 시스템은 **클라우드 AI(피클 비서)**와 **집 리눅스 노트북(실행 엔진)**이 GitHub를 매개로 유기적으로 협업하는 24/7 무중단 트레이딩 아키텍처입니다.

```text
[집 리눅스 노트북 (홈 서버)]
   │  - 24/7 systemd 무중단 데몬 가동 (파이썬 표준 라이브러리 전용, 무설치)
   │  - 장중 30초 주기 키움 REST API 시세 감시 및 조건 평가
   │  - 조건 부합 시 SOR 시장가 자동 주문 (매수/매도 집행)
   │
   ├─► [체결 발생 시] ──► GitHub main 브랜치 (trades.json 업데이트)
   │                             │
   │                             ▼
   │                   [피클 비서 (클라우드)]
   │                      - 5분 주기 체커(check.sh)로 감지 (토큰 0원)
   │                      - 체결 즉시 용태 님 스마트폰으로 실시간 알림!
   │                      - 매주 월요일 08:00 주간 결산 & 전략 진단 선보고
   │
   └─► [30분 주기 생존 핑] ──► GitHub status 브랜치 (단일 커밋 덮어쓰기)
                                 │ (0.1KB, 메인 잔디/히스토리 오염 0%)
                                 ▼
                       [스마트폰에서 "봇 잘 돌아?" 질문 시 즉시 1초 브리핑!]
```

## 🛡️ 4. 세부 전략 규칙

### ① 감시 유니버스: 시총 1조 ~ 5조 원 동적 스크리닝
- **작전주·동전주 배제**: 시총 1조 원 미만, 우선주, 스팩, ETN 원천 차단.
- **초대형 메가캡 배제**: 시총 5조 원 초과 메가캡을 제외하여 주도 섹터 수급 유입 시 탄력성 확보.
- **전일 확정치 기준**: 매일 장 개장 전(08:50) 전일 거래대금 최상위 20종목 자동 추출.

### ② 2대 콤비 진입 전략
1. **과매도 저격매수 (RSI Reversal)**:
   - 전일 14일 RSI가 **28.0 이하**였다가 당일 **30.0을 상향 돌파**하고 양봉 반등한 경우에만 매수.
2. **추세 필터 변동성 돌파 (Trend VBO)**:
   - 시장 프록시가 상승하는 60일선 위에 있을 때만 작동.
   - 주가가 상승하는 20일선 위에서 전일 레인지(K=0.5)를 현재가 기준 돌파하고, 장중 경과시간으로 보정한 거래량 속도가 20일 평균의 1.5배 이상일 때 매수.
3. **공통 진입 품질 필터**:
   - 4% 초과 갭 상승, 당일 10% 초과 급등, 윗꼬리 비율 40% 초과 종목 제외.
   - 장 초반 노이즈와 장 마감 유동성 위험을 줄이기 위해 09:15~14:30에만 신규 진입.
   - 필터는 승률을 보장하지 않으며 거래 수와 기대수익을 함께 검증해야 함.

### ③ 리스크 관리 및 청산 규칙
1. **ATR 기반 동적 손절**: 진입 시점 14일 ATR의 1.5배(2.5%~4.0% 밴드)로 손절선 유연 설정.
2. **트레일링 스탑**: 주가 **+4.0%** 도달 시 손절선을 매수가 위(**+1.0%**)로 상향하여 확정 수익 보존.
3. **최소 1:2 손익비 목표 익절**: 손절폭의 최소 2배 이상(+8.0% 기준) 목표 도달 시 전량 청산.
4. **타임스탑 & 일일 킬스위치**: 최대 7거래일 내 미청산 시 타임스탑 청산, 계좌 당일 누적 손실 -4% 도달 시 당일 올스톱.
5. **자금 배분**: 1종목당 계좌 총자산의 최대 20%, 최대 4종목 동시 보유 (최소 20% 현금 버퍼 유지).

## 🚀 5. 집 리눅스 노트북 설치 및 가동 방법

키움 REST API는 구형 32비트 OCX·DLL 설치가 전혀 필요 없는 최신 REST 규격이며, 외부 파이썬 패키지 의존성 없이 표준 라이브러리(`urllib`, `json`)만으로 100% 가동됩니다.

### 1단계: 저장소 최신화
```bash
cd quant-sniper
git pull
```

### 2단계: 키움 API 실전투자 키 입력 (.env)
```bash
cp .env.example .env
nano .env
```
`.env` 파일에 발급받으신 키움증권 REST API 키를 입력합니다:
```env
KIWOOM_APP_KEY=발급받은_실전_APP_KEY
KIWOOM_APP_SECRET=발급받은_실전_APP_SECRET
KIWOOM_ACCOUNT_NO=실전_계좌번호_8자리
KIWOOM_ACCOUNT_TYPE=01
KIWOOM_USE_MOCK=true
LIVE_TRADING_ENABLED=false
ORDER_CONFIRM_TIMEOUT_SECONDS=20
```
*(※ `.env`는 `.gitignore` 최상단에 등록되어 GitHub에 절대 커밋되지 않습니다.)*

실전 전환은 모의투자 검증 후 `KIWOOM_USE_MOCK=false`와
`LIVE_TRADING_ENABLED=true`를 **둘 다** 설정해야 합니다. 하나라도 충족되지 않으면
실전 API 시작을 거부합니다.

### 주문·계좌 안전 규칙

- 주문 접수만으로 체결 처리하지 않고 `kt00009` 체결 조회에서 주문수량 전체와 실제 가중평균 체결가를 확인합니다.
- 체결 확인 실패 시 로컬 장부를 변경하지 않고 그날의 신규 주문을 중단합니다.
- `kt00018` 실계좌 잔고와 로컬 포지션이 다르면 신규 주문을 중단합니다.
- 동적 유니버스에서 빠진 기존 보유 종목도 별도로 계속 감시합니다.
- 일일 손실 킬스위치 상태, 보유일수, 트레일링 상태를 재시작 후에도 보존합니다.
- ETF·ETN·스팩·우선주는 개별주 전략의 신규 유니버스에서 제외합니다.
- 동일 프로세스의 중복 실행을 잠금 파일로 차단합니다.

실전 키를 연결하기 전에 공식 모의투자 환경에서 주문 접수·부분체결·거절·재시작
시나리오를 반드시 확인해야 합니다. 저장소의 자동 테스트는 API 형식과 내부 상태 전이를
검사하지만 실제 키움 서버의 전체 체결 흐름을 대신하지 않습니다.

### 3단계: 봇 가동 (2가지 방법 중 선택)

#### 방법 A: 스크립트 백그라운드 실행
```bash
chmod +x run.sh
./run.sh
```

#### 방법 B: systemd 데몬 등록 (상시 가동 권장)
```bash
sudo cp quant_sniper.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now quant_sniper
```

## 💻 6. 노트북 덮개 닫힘 시 절전 방지 설정 (필수)

노트북 덮개를 닫은 채 상시 서버로 운용하려면 리눅스 절전 방지 설정을 적용합니다:
```bash
sudo nano /etc/systemd/logind.conf
```
아래 항목의 주석(`#`)을 해제하고 `ignore`로 변경 후 저장:
```ini
HandleLidSwitch=ignore
HandleLidSwitchExternalPower=ignore
HandleLidSwitchDocked=ignore
```
설정 재적용:
```bash
sudo systemctl restart systemd-logind
```

## 🩺 7. 헬스체크 및 피클 비서 연동

- **폰에서 비서에게 질문**: 피클 채팅창에 **"봇 잘 돌아?"** 질문 시 비서가 `status` 브랜치를 확인하여 즉시 1초 브리핑.
- **장중 실시간 체결 알림 (`every 5m`)**: 체결 발생 즉시 스마트폰 알림 발송 (무거래 시 토큰 소모 0원).
- **주간 성과 결산 (`weekly mon 08:00`)**: 매주 월요일 아침 8시 주간 실현손익, 승률, 슬리피지 분석 및 전략 진단 선보고.

## 📂 8. 프로젝트 폴더 구조

```text
quant-sniper/
├── config.py             # 1조~5조 필터, ATR 동적 손절, 거래비용(0.41%), 키움 API 설정
├── screener.py           # 전일(D-1) 확정 거래대금 TOP 우량주 동적 스크리너 (Lookahead 방지)
├── strategy.py           # RSI 과매도 반등, 변동성 돌파 및 ATR 손익비 엔진
├── env_loader.py         # 외부 패키지 없는 .env 로더
├── kiwoom_api.py         # 키움증권 최신 공식 REST API 래퍼 (무설치, SOR 시장가 집행)
├── bot.py                # 24/7 메인 감시 루프 및 status 브랜치 헬스체크 엔진
├── run.sh                # Git 권한 사전 검증 및 nohup 백그라운드 실행기
├── quant_sniper.service  # systemd 무중단 자동 재시작 서비스 파일
├── trades.json           # 누적 체결 장부 (비서 실시간 동기화용)
├── positions.json        # 현재 보유 포지션 관리 장부
├── health.json           # 로컬 1분 주기 헬스체크 파일
├── .env.example          # 키움 API 키 템플릿
├── tests/                # 주문·계좌 안전장치 자동 테스트
└── .gitignore            # 민감 파일(.env 등) 깃 제외 목록
```
