# quant-sniper
> **키움증권 REST API 기반 고수익 저위험 스나이퍼 퀀트 트레이딩 봇**

서용태 님(@rundevelrun)의 개인 자산 스케일업을 위한 완전 자동화 알고리즘 트레이딩 시스템입니다.

---

## 1. 전략 개요 (손익비 비대칭 저격매매)

- **핵심 철학**: 승률 100%를 노리는 환상이 아닌, **"잃을 땐 쥐꼬리(-2.0%)만큼 자르고, 벌 땐 크게(+4%~+8%) 먹는 비대칭 손익비"**를 기반으로 계좌를 우상향시킵니다.
- **2대 콤비 전략**:
  1. **RSI 극단 과매도 반등**: 대형 우량주가 시장 공포로 14일 RSI 28 이하를 터치할 때 분할 저격 매수.
  2. **추세 필터 변동성 돌파**: 주가가 20일 이동평균선 위에 위치한 우상향 상태에서 전일 변동폭(K=0.5)을 뚫어낼 때만 진입.
- **3대 철벽 안전장치**:
  1. **-2.0% 기계적 칼손절**: 어떤 이유든 진입가 대비 -2% 터치 시 1초 만에 자동 시장가 청산.
  2. **트레일링 스탑 (수익 보존)**: 수익률이 +4.0%를 넘어서는 순간 손절선을 본전 위(+1.0%)로 자동 상향하여 수익을 잠금.
  3. **일일 킬 스위치 (Daily Kill Switch)**: 하루 누적 계좌 손실이 -4.0%에 도달하면 당일 매매 즉시 전면 셧다운.
- **🔍 당일 실시간 동적 유니버스 스크리너 (Dynamic Screener)**:
  - 종목을 고정하지 않고, 매일 아침 장 시작 전 시장에서 **시가총액 1조 원 이상 ~ 5조 원 이하 우량주 중 당일 거래대금 최상위 20종목**을 실시간 자동 스크리닝합니다. (잡주/스팩 원천 배제 + 굼뜬 10조+ 메가캡 배제 = 탄력적 황금구간)

## 3. 폴더 구조

```text
quant-sniper/
├── config.py             # 전략 파라미터, 동적 스크리너 옵션, 키움 API 설정
├── screener.py           # 당일 거래대금 TOP 우량주 실시간 동적 스크리너
├── strategy.py           # RSI 계산, 변동성 돌파 타겟, 신호 랭킹 알고리즘
├── kiwoom_api.py         # 키움증권 REST API 연동 (모의투자 및 실계좌)
├── bot.py                # 24/7 메인 감시 및 자동 매매 집행 루프
├── run.sh                # 백그라운드 원클릭 실행 스크립트
├── quant_sniper.service  # 리눅스 systemd 데몬 등록 파일
├── trades.json           # 체결 장부 (비서 자동 동기화용)
├── .env.example          # API 키 설정 템플릿
└── .gitignore            # 민감 파일(.env 등) 깃 제외
```

## 4. 집 리눅스 노트북 실행 방법

### 1) 저장소 클론 및 이동
```bash
git clone https://github.com/rundevelrun/quant-sniper.git
cd quant-sniper
```

### 2) 가상환경 설정 및 의존성 설치
```bash
python3 -m venv venv
source venv/bin/activate
pip install requests
```

### 3) API 키 세팅 (.env)
```bash
cp .env.example .env
nano .env
# 키움증권 모의투자 App Key, Secret, 계좌번호 입력 후 저장
```

### 4) 실행하기
```bash
# 일반 백그라운드 실행
chmod +x run.sh
./run.sh

# 또는 systemd 서비스로 24시간 무중단 등록 (권장)
sudo cp quant_sniper.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now quant_sniper
```

## 5. 비서(피클) 거래 보고 및 주간 전략 진단
- **실시간 체결 알림**: 봇이 매수/매도 주문을 체결하면, 체결 내역을 `trades.json`에 기록하고 자동으로 깃허브에 푸시합니다. 피클 비서가 30분 주기 체커(`check.sh`)를 통해 새 거래를 감지하여 피클 채팅창으로 즉시 브리핑합니다 (거래 없을 시 토큰 소모 0).
- **주간 성과 결산 및 전략 진단**: 매주 월요일 오전 08:00(장 개장 1시간 전), 비서가 지난 한 주간의 누적 거래 데이터(승률, 실현손익, MDD, 슬리피지)를 전수 분석하여 주간 영수증 카드와 함께 **"전략 유지 or 파라미터 수정 권고 리포트"**를 선보고합니다.
